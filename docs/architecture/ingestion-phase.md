The `GrantPolicy` checks a supplied exact source, scope, method and use against an approved source, evidence, validity and revocation. It is not wired to a grant repository and does not establish permission by itself. `PayloadEvidence` hashes raw bytes and rejects backdated availability; it does not store payloads. `Idempotency` hashes explicitly supplied effect inputs; it does not implement transaction deduplication. No retention, publication, training, access-country or grant revocation enforcement is operational.
